## 适用范围

适用于 `internal/infra/gitcli/`，继承[后端规则](../../AGENTS.md)。本文件约束 Git 适配实现；当前 AnyCode 卡片工作树的管理限制仍由项目根规则约束。

## 分支与工作树

- [git.go](git.go) 管理 Git 探测、分支、worktree 和工作区快照；分支存在检查区分精确本地与远端引用，并覆盖空仓库。
- ownership 检查同时核对仓库关联、worktree 分支和所有权标记 token；不能只凭路径存在认定归属。
- 创建失败保留原有分支、目录与其他任务的标记；上下文取消不能继续触发破损 worktree 的兜底删除。
- 快照处理暂存、未暂存及未跟踪文件，保留目录边界检查；修改时覆盖符号链接和相对数据目录场景。
- 创建 worktree 使用已获取的分支，删除分支不额外 fetch；不要把隐式网络操作加入本地清理路径。

## 验证

在仓库根运行 `go test ./internal/infra/gitcli`；沿用 [git_test.go](git_test.go) 创建的临时仓库验证归属、失败回滚、并发标记和快照行为。
